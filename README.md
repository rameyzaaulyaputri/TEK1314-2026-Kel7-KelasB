## Deskripsi Skenario — Kelompok 7

Kelompok 7 mensimulasikan serangan siber terhadap aplikasi web yang terhubung dengan basis data, menggunakan target Metasploitable 2 / DVWA. Red Team akan mendemonstrasikan eksploitasi celah keamanan berupa:
- SQL Injection dan Cross-Site Scripting (XSS) melalui port 80 (HTTP)
- Ekstraksi data sensitif dari database melalui port 3306 (MySQL)
- Brute-force autentikasi melalui port 22 (SSH)

Seluruh aktivitas serangan akan dipantau oleh Monitoring Node (Security Onion) yang ditempatkan pada mirror/span port switch untuk menangkap lalu lintas jaringan di seluruh segmen (192.168.7.0/24).
